# Simple Sales Dashboard Design 

## Objective
To build a simple interactive dashboard using Tableau that visualizes sales performance by product category, region, and month.

## Tools Used
- Tableau Public
- Superstore Sales Dataset (CSV format)

## Steps Followed
1. Imported the Superstore dataset into Tableau.
2. Converted the "Order Date" column to a "Month-Year" format.
3. Created the following visuals:
   - **Line Chart:** Sales over time (Month-Year)
   - **Bar Chart:** Sales by Region
   - **Donut Chart:** Sales by Product Category
4. Added a slicer (filter) for Region.
5. Used color encoding to highlight high-performing areas.

## Key Insights
- Technology category led in overall sales and profit.
- The West region had the highest sales in Q3.
- There was a dip in Furniture sales during mid-year.
- Sales consistently increased toward the end of the year.
